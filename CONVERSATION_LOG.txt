APP CONCEPT DESCRIPTION
==============================================================================

USER PROVIDED DETAILED APP SPECIFICATION:

APP NAME: "O' U Scape Route"

CORE FEATURES:
1. SOCIAL MEDIA ACCOUNT MANAGER
   - Users can log in to multiple social media platforms
   - Support for: Facebook, Instagram, Twitter, TikTok, YouTube, Snapchat
   - OAuth/credential-based authentication

2. SESSION MANAGEMENT
   - When app is closed/backgrounded and reopened, social media accounts disappear
   - Display switches to game hub/main display instead

3. GAME HUB
   - List of games for user selection
   - Games playable within the app
   - Acts as primary display when app restarts

4. HIDDEN PREMIUM/PRO ACCESS SYSTEM
   - Settings has "Premium/Pro" option
   - Actually a code/PIN entry system (number combination)
   - PIN unlocks access to saved social media accounts

5. ACCOUNT PERSISTENCE
   - Option to save social media credentials
   - Users don't need to re-enter accounts repeatedly
   - Quick re-login capability

6. ACCOUNT MANAGEMENT SETTINGS
   - Separate app-specific settings
   - Option to clear/erase all saved social media accounts
   - Account-specific settings

7. MINI APP STORE
   - Browse available apps/games
   - Install/add apps to the device
   - Uninstall functionality
